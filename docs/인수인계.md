# KoK 프로젝트 인수인계 (2026-11-10 기준)

다른 컴퓨터의 Claude가 이 프로젝트를 이어서 도울 때 읽는 문서다. 지금까지의 대화에서 정한 것, 확인한 숫자, 남은 일을 모았다.

## 0. 사용자와 대화할 때 지킬 것
- **항상 한국어로**, 쉽고 짧게 설명한다. 영어로 답하면 안 된다. 전문 용어는 풀어서 말한다.
- 무엇을 할지 단계별로 구체적으로 알려 준다. 말없이 길게 작업하지 말고 중간중간 알린다.
- **수집한 피싱 URL은 절대 브라우저로 열지 않는다.** 문서·답변에는 `hxxp://example[.]top`처럼 눌리지 않게 적는다.
- **C 드라이브 여유 공간이 적다.** 큰 파일을 받기 전에 확인한다.
- 토큰·비밀번호는 채팅에 붙여넣게 하지 않는다. 사용자가 터미널에 직접 입력하게 한다.
- 학교 양식 문서를 다룰 때는 형식을 그대로 지킨다(예전에 HWP를 docx로 바꿔 줬다가 혼난 적 있음).

## 2. 판정 흐름 (서버)
1. 공식 주소 목록(39개 규칙, `.go.kr` 포함) → 안전 (앱도 휴대폰 안에서 먼저 확인)
2. 피싱 목록(KISA·PhishTank, 도메인 39,504 · 주소 55,394) → 위험 100
3. 단축 URL 풀기: Location 헤더만, 최대 5회·1.5초, 내부망 차단, 페이지 안 엶
   - 삭제된 단축 주소(404) → 주의 50 / 단축 서비스가 차단한 주소(bitly.com/a/warning) → 위험 90 / 목적지 모름 → 확인 못 함
   - 목적지 사이트까지 찾은 뒤 시간이 넘으면 찾은 목적지로 판정
4. CANINE v2 확률 → 점수: p<0.05 → 0~39 안전 / 0.05~0.5 → 40~69 주의 / ≥0.5 → 70~100 위험
5. 보정: 규칙(브랜드 흉내·위험 TLD·IP·포트·퓨니코드·의심 단어) 바닥 점수 45/75, 주소 정보(DNS 없음 → 주의 45, RDAP 30일 이내 새 주소 → 주의, 새 주소+위험 신호 → 75), 유명 사이트(Tranco 상위 10만, 99,954개)는 최대 69(주의)
- 앱 대기 시간 4초. 주의는 바로 열지 않고 확인 창([확인하고 열기]/[열지 않기])

## 3. AI 모델
- `google/canine-s` 미세조정, 2분류. 입력은 `http://`·앞 `www.`를 뗀 URL 최대 256자
- 설정: lr 2e-5, batch 32, 3 epoch, warmup 0.06, weight decay 0.01, fp16, 검증 F1 최고 회차 선택, 조기 종료
- 기준점 0.05 (검증셋에서 오탐률 5% 이하 중 재현율 최고)
- 데이터(v2): 피싱 KISA 2023~24 34,167 + PhishTank 51,211 = 85,378 / 정상 Tranco 45,503 + Common Crawl 35,085 + 한국어 위키백과 4,790 = 85,378
  - 학습 ~2025.12 64,049쌍 / 검증 2026.1~4 7,895쌍 / 시험 2026.5~10 13,434쌍
  - KISA는 2024.12분이 최신 공개본. v2 검증·시험은 PhishTank만
- v1(학습 ~2024.06, 41,247쌍): 2024.10~12 시험 정확도 92.3, 정밀도 98.0, 재현율 86.4, F1 0.918, 오탐률 1.7%, AUC 0.975. 검증(2024.7~9) 재현율 97.9
- **v2 결과(2026.5~10, 26,868개)**: 정확도 89.8, 정밀도 98.4, 재현율 81.0, F1 0.889, 오탐률 1.32%, AUC 0.956
- v1을 같은 시험지로: 정확도 89.3, 재현율 80.4, F1 0.883, 오탐률 1.70
- 손실(v2): 학습 0.062/0.052/0.043, 검증 0.159/0.136/0.169 → 2 epoch 선택(3 epoch 과적합). v1: 학습 0.072/0.043/0.032, 검증 0.100/0.084/0.095
- 시간에 따른 하락: v1 재현율 **학습 4~6개월 뒤 86.4% → 약 2년 뒤 80.4%** ("3개월/1년 반"은 틀린 표현)
- 무작위 분할 실험은 **하지 않았음** ("무작위면 98%" 같은 말은 쓰면 안 됨)
- 직접 분석: 2024.10~12 KISA 피싱 도메인의 81.3%가 그전 데이터에 없던 새 도메인 / KISA 피싱 URL의 34.6%(18,099/52,266)가 단축 URL

## 4. 배포 구조 (중요)
- Hugging Face 계정 `6hzl`. 모델: https://huggingface.co/6hzl/kok-canine (공개, v2)
- **HF 무료 계정은 Docker Space 불가(PRO 월 9달러 필요)** → 검사 서버는 **노트북 + Cloudflare 무료 터널**
- `server/run_public.py`: 서버 켜기 + 터널 + 새 주소를 `6hzl/kok-canine`의 `endpoint.txt`에 기록, 1분마다 확인해 끊기면 자동 재연결. HF 쓰기 토큰 필요. **두 컴퓨터에서 동시에 켜면 안 됨**
- 앱(-Ppublic 빌드)과 웹 데모는 endpoint.txt를 읽어 서버를 찾음
- 웹 데모: https://6hzl-kok-demo.static.hf.space (HF 정적 Space, 무료·고정) / https://hyeri222.github.io/kok-web-demo/
  - 주소 뒤 `#shot=inbox|danger|caution|unknown|kok|history`로 화면 바로 열기
- GitHub: https://github.com/hyeri222/smishing-url-explorer (비공개, 협업자 ummpa) / https://github.com/hyeri222/kok-web-demo (공개, 데모와 화면 캡처 `images/`)
- 피싱 목록 파일(blacklist_*.txt)은 GitHub 코드에 없음 → 비공개 저장소 Release `data-v1`에 있음
- 모델 파일·학습 데이터는 GitHub에 없음(모델은 HF에서 받음)
- 안드로이드: Kotlin, minSdk 29, targetSdk 37, Gradle 9.6/AGP 9.4, `gradlew assembleDebug -Ppublic` → 데모 APK
